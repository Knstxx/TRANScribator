GPT App is now the fourth transcription option. It reuses the existing session of a compatible installed ChatGPT/Codex app without a separate sign-in flow or Platform API key. Missing or expired sessions disable the option and show an actionable message.

- Long recordings use parts up to **9 minutes 50 seconds** for GPT App, with a separate 24 MB upload guard. A one-hour recording produces seven parts.
- Audio/video file transcription and recording cancellation are available from the menu bar. Cancelling file transcription stops local preparation, the current request and subsequent parts; recordings can also be discarded before upload.
- A new app icon, status badges and compact audio controls make recording, muted sources, processing and errors visible in both appearance modes.
- Session credentials stay out of settings and logs. The app verifies the OpenAI helper's signature, refuses HTTP redirects and never falls back from GPT App to the paid API.

**Downloads:** Universal DMG and ZIP for Apple Silicon and Intel, plus SHA256SUMS. Requires macOS 15 or later. The three API models still require an OpenAI API key stored in macOS Keychain.

This is an ad-hoc signed preview build, not a notarized Developer ID release. On first launch, macOS may require **System Settings → Privacy & Security → Open Anyway**. GPT App uses an internal ChatGPT interface whose compatibility and service limits may change; it currently supports compatible apps with the bundled Codex helper and shared managed profile.

Validation includes macOS core/audio checks, offline session and HTTP security checks, light/dark status rendering, Python tests/lint and dependency audits.
