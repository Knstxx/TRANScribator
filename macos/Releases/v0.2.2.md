# Transcribator 0.2.2

Исправлено ложное «Добавьте OpenAI API key» при обработке файла из командной строки: служебный запуск больше не создаёт меню с отдельным состоянием. Обычное меню повторно проверяет наличие ключа и различает отсутствие ключа и ошибку Связки ключей.

GPT App теперь делит аудио на части не длиннее пяти минут. Это уменьшает риск обрезанных ответов, наблюдавшихся при прежних частях около десяти минут. Сервер не сообщает надёжный признак полноты распознавания, поэтому ограничение не гарантирует отсутствие отдельных ошибок или пропусков речи.

Добавлен необязательный CLI-отчёт `--diagnostics` для GPT App: только HTTP-статус, размеры текста и разрешённые имена полей ответа. Токены, заголовки запросов, текст и значения аудиообъектов в него не попадают.

Проверены состояния ключа, отмена и авторизация на подставных данных, границы пяти минут, полное сохранение длинного ответа и интерфейс в обеих темах. В контрольном сравнении двух почти пятиминутных фрагментов с их короткими половинами систематического обрезания окончаний не обнаружено; это ограниченная проверка, а не измерение точности распознавания.

Universal для Apple Silicon и Intel, macOS 15+. Preview-сборка подписана ad-hoc, без нотарификации Apple.
