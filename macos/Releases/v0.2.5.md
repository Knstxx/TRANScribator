# Transcribator 0.2.5

Пустой ответ GPT App на участке без речи больше не обрывает транскрибацию всей встречи. Такая часть повторно проверяется фрагментами до минуты; обычный предел остаётся 5 минут. Участки без распознанной речи отмечаются отдельно, а полностью пустая запись выдаёт понятное сообщение.

Промежуточный текст сохраняется после каждого ответа и остаётся доступным при ошибке или отмене. Единственная копия аудио сохраняется при ошибке даже при выключенном сохранении записей; файлы после аварийного завершения переносятся в папку восстановления. Существующий итоговый TXT не перезаписывается.

Universal для Apple Silicon и Intel, macOS 15+. Preview-сборка подписана ad-hoc, без нотарификации Apple.
